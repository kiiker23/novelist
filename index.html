        How to Connect Locally (Ollama Guide)

        Step 1 — Install Ollama

        Download from ollama.com. Run the installer and launch Ollama. It runs silently in your system tray.

        Step 2 — Pull a Model

        Open Command Prompt and run:

        ollama pull llama3.2

        Or for larger models: ollama pull mistral / ollama pull codellama

        Step 3 — Verify It's Running

        Ollama exposes an API at http://localhost:11434 by default. Test it:

        curl http://localhost:11434/api/tags

        You should see a JSON list of your pulled models. If this fails, Ollama may not be running.

        Step 4 — Firewall / Port Forwarding (if needed)

        Ollama listens on port 11434. On Windows:

        1. Open Windows Defender Firewall → Advanced Settings
        2. Inbound Rules → New Rule → Port → TCP → Specific local ports: 11434
        3. Allow the connection → Apply to Domain/Private/Public → Name: Ollama API

        On Linux: sudo ufw allow 11434/tcp or sudo iptables -A INPUT -p tcp --dport 11434 -j ACCEPT

        To access from another machine on your network, use http://YOUR_IP:11434 instead of localhost.

        Alternative: LM Studio

        Download from lmstudio.ai. Start the local server, and set the endpoint to http://localhost:1234/v1 (LM Studio uses OpenAI-compatible format).
